Aesthetic Puzzle

This Privacy Policy explains how Aesthetic Puzzle handles user information when the game is installed and played on Android devices through Google Play.

Last updated: April 13, 2026

Information We Collect

Aesthetic Puzzle does not collect, store, transmit, or sell personal information from users.

Game Functionality

The game is designed to run as a standalone Unity-based experience without user account registration, sign-in, analytics dashboards, or cloud-based profile storage.

Permissions

Aesthetic Puzzle does not request access to sensitive permissions such as camera, microphone, contacts, location, or photos and files, except for technical permissions automatically required by the Android system to install and run the game properly.

Third-Party Services

Aesthetic Puzzle does not use third-party services for advertising, analytics, social login, crash tracking, or remote data storage.

Children's Privacy

Because Aesthetic Puzzle does not collect personal information, it does not knowingly collect personal data from children or from any other users.

Data Sharing, Retention, and Deletion

Since no personal data is collected, there is no personal data to share, retain, or delete.

Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. Any future changes will be posted on this page together with the revised "Last updated" date.
