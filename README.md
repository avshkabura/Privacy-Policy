# Privacy-Policy

GitHub Pages privacy policy hub for Google Play app and game listings.

Direct links:

- `Aesthetic Puzzle`: `https://avshkabura.github.io/Privacy-Policy/aesthetic-puzzle.html`
- `AlienCore: Contact`: `https://avshkabura.github.io/Privacy-Policy/aliencore-contact.html`
- `Health Discipline`: `https://avshkabura.github.io/Privacy-Policy/health-discipline.html` (English and Ukrainian)

Suggested structure:

- `index.html` is the landing page with links to all policies.
- Each app or game should have its own dedicated HTML page.
- In Google Play Console, use the direct link for the specific app or game instead of the hub page.
